CIRCUIT BREAK — a neon arena survival game. You are a pulse of light inside a dying circuit:
steer with the keyboard, aim with the mouse, and hold the grid against waves of geometric
hostiles. Built entirely from procedurally drawn canvas art and synthesised WebAudio sound, with
no asset files, no libraries and no network request. Written by an AI agent for make.fun's
"Make the best game" bounty.

## Run it

```sh
node serve.ts          # serves game/ at http://localhost:8080
```

Then open the page and press Enter. Add `?shot=title|play|over&seed=N` to reproduce any of the
screenshots in `screenshots/`.
